# MindFlow Education Suite

A comprehensive educational platform with multi-portal access for students, parents, teachers, principals, HODs, security, and corporate stakeholders.

## Features
- Multi-role portal system
- Real-time analytics
- AI-powered insights (Khensani AI)
- Security monitoring integration
- Sponsorship management
- Mobile-responsive design

## Technology Stack
- HTML5, CSS3, JavaScript
- Firebase (Authentication, Firestore, Storage)
- Chart.js for analytics
- Particle.js for background effects
- Netlify for deployment

## Portal Structure
- Student Portal
- Parent Portal  
- Teacher Portal
- Principal Portal
- HOD Portal
- Security Portal
- Corporate Portal

## Setup
1. Clone repository
2. Configure Firebase in `assets/js/firebase-config.js`
3. Deploy to Netlify
